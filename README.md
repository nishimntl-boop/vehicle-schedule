# 車両・人員予定表 GitHub Pages版 v51

v47を安定基盤として、v48/v49の操作・表示機能を維持し、共有保存競合とPWAキャッシュを再点検した版です。

## v51の重点修正
- PC・スマホの同時編集で、送信中に別の編集をしても古い保存結果で画面を巻き戻さない
- 保存要求をキュー化し、短時間に連続編集しても最後の変更まで順番にGASへ送信
- 保存中は古いクラウド読み込みでローカルの未送信変更を上書きしない
- 予定単位の dirtyEventIds + updatedAt によるGAS側競合解決を採用（旧クライアント互換あり）
- 空き状況を予定・確定・休みの割当から算出
- 週予定に未割当行を用意
- 日またぎを「🌙 日またぎ」で月・週・日に明示
- 確定色は30色を系統が連続しにくい順で使用。赤は重複時のみ
- PWAサービスワーカーをv51キャッシュへ更新

## GitHub Pages
GitHub Pagesで公開するファイルは `index.html` です。`index_v48.html` など旧版HTMLは不要です。

## GAS
`gas/Code.gs` は共有競合対策を含むv50系バックエンドです。既存のGAS Webアプリを更新する場合は、必ず新しいデプロイ版へ更新してください。
v47の安定版は別ファイルとして保持してください。
