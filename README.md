# 車両・人員予定表 GitHub Pages版 v53

v47を安定基盤として、v51/v52の共有・表示・色分け機能を維持し、**予定→確定など区分だけを変更した際に車両・人員の割り当てが消える不具合**を修正した版です。

## v53の重点修正
- 予定を「予定→確定」「確定→予定」に変更しても、既存の車両・人員割り当てを維持
- 車両・人員チェックボックスを実際に変更した場合だけ、その変更内容を保存
- デスクトップ画面とスマホのモーダルのどちらから保存しても同じ扱い
- 共有同期時のv51系競合対策を維持
- 空き状況、週予定の未割当、🌙日またぎ表示を維持
- 同一日・近接日の現場色を見分けやすくするv52の色分けを維持
- PWAサービスワーカーをv53キャッシュへ更新
- `index_v48.html` は含めない

## GitHub Pages
GitHub Pagesで公開するファイルは `index.html` です。旧版HTMLは不要です。

## GAS
`gas/Code.gs` はv51系の共有競合対策版を同梱しています。今回のv53修正は主にGitHub Pages側の予定編集処理です。
既存のGAS Webアプリを更新する場合は、現在使用している共有バックエンドを不用意に戻さず、v51系の修正版を基準にしてください。

## 安定版
