# 車両人員予定表 GitHub Pages版 v47修正版（v47fix4）

v47の元ZIPは変更せず、そこから直接修正した版です。起動順序を整理し、PC/スマホの編集と共有保存を差分パッチ方式に変更しています。

## 主な修正
- 初期化順序を一本化し、関数定義前の `render()` / `rebuildChecks()` 呼び出しを排除。
- PC・スマホの両方で、追加・編集・削除・「予定」⇄「確定」変更を可能にしたまま維持。
- 既存予定を編集して区分だけ変更した場合、車両・人員の割当を保持。
- 車両・人員の変更もPC/スマホ双方で保存。
- 共有保存は予定全件の上書きではなく、変更した予定だけをGASへ送信。
- GAS側はLockService中にSpreadsheetを強制再読込し、古い端末の状態で新しい割当を上書きしない。
- 削除済み予定の復活を防ぐため、削除トゥームストーンを保持。
- 保存中に別の編集が入っても、保存中のスナップショットと後続編集を分離。
- 未割当予定を週予定に専用行で表示。
- 日またぎ予定に `🌙日またぎ` を表示。
- `予定` は灰色、`休み` はピンク、ダブルブッキングだけ赤。
- 確定予定は現場ごとの色。30色の通常色パレットから、同日・近接日の色が離れるように選択。
- PWAキャッシュをv47fix4へ更新。

## GAS更新が必要です
今回のGAS読み込みエラー対策もGAS側に含まれています。`gas/Code.gs` をGASプロジェクトへ反映し、Webアプリを新しいバージョンで再デプロイしてください。

設定：
- 実行ユーザー：自分
- アクセスできるユーザー：全員

## GitHub Pages
`index.html`、`manifest.json`、`sw.js`、`icons/` をGitHub Pagesへ反映してください。

## 注意
v47元ZIPは別ファイルとして保存し、このZIPで上書きしないでください。
