# 車両・人員予定表 GitHub Pages版 v49

- 週予定に「未割当」行を追加。人員・車両を未選択の予定も週予定で確認可能
- 空き状況を予定／確定の割当だけでなく「休み」も反映
- 日またぎ予定を `🌙 日またぎ` と明示し、枠線も付けて視認性を向上
- 月・週・日の表示で日またぎ表示を統一
- v47の共有方式・GASバックエンドは変更していません
