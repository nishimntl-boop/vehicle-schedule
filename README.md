# 車両・人員配置管理 v44

スマートフォンの文字サイズ・ボタンサイズ・入力欄・チェックボックスを見やすくし、指で操作しやすくした版です。

- 共有通信はv43のGAS直接方式を維持
- PC向けレイアウトは維持
- スマートフォンでは幅1000px以下かつタッチ操作端末に最適化
- 月予定はスマホ幅に収まるよう改善
- 週予定・日予定は必要に応じて横スクロール可能
- 入力欄、ボタン、チェックボックスを大型化


## v46 共有通信方式
- GitHub PagesからGASを直接開きません。
- 読み込み：GASのJSONP API
- 保存：hidden form POST → doPost
- CORS/iframe内GAS UIに依存しない構成です。

### 重要：GASデプロイ設定
GitHub Pagesから匿名で共有APIを呼べるよう、Webアプリのアクセス権を **「全員（匿名ユーザーを含む）」** にしてください。
実行ユーザーはこれまで通り **「自分」** で構いません。

この設定が「全員（ログインユーザー）」のままだと、スマホの通常ChromeでGoogleアカウントのセッションによって弾かれる可能性があります。
